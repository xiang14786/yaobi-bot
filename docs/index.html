💡 早分（Early Score）是什麼？
由 BB壓縮、成交量、ATR 等「尚未啟動」的指標組成，早分高代表「還沒大漲但蓄勢完成」，是提前佈局的關鍵信號。
📡指標解說▼
🎯 BB 布林帶
Bollinger Bands
以 20 日均線為中軌，上下各加減 2 倍標準差。當上下軌收窄（壓縮）代表市場蓄勢，即將大幅波動。
▲ 壓縮後向上突破 = 多頭啟動
▼ 壓縮後向下跌破 = 空頭啟動
📐 OB 訂單塊
Order Block
機構下大單前的最後一根反向 K 線，代表機構進場的價格區間，之後常作為強支撐或強阻力。
▲ 價格回測 OB 多頭區域 = 買點
▼ 跌破 OB = 結構轉空
📐 FVG 價值缺口
Fair Value Gap
三根 K 線快速移動時留下的缺口，市場傾向回填此缺口，代表潛在支撐/阻力區。
▲ 在 FVG 支撐區止跌 = 做多機會
💰 FR 資金費率
Funding Rate
永續合約每 8 小時結算一次。正值代表多頭付費給空頭，負值反之。極端值是反向指標。
▲ FR 負值 = 空頭承壓，多頭有利
▼ FR 極正 = 多頭擁擠，注意回調
📦 OI 未平倉量
Open Interest
市場上所有未平倉合約的總量（以 USDT 計價）。OI 增加代表新資金進場，反之代表離場。
▲ OI 增加 + 價格上漲 = 多頭建倉
▼ OI 增加 + 價格下跌 = 空頭建倉
📊 RSI 相對強弱
Relative Strength Index
0–100 的動能指標。低於 30 = 超賣（可能反彈），高於 70 = 超買（可能回調）。
▲ RSI < 30 從超賣回升 = 買點
▼ RSI > 75 = 過熱警示
🐋 頂級多空比
Top Long/Short Ratio (Binance 前 20%)
Binance 資金量前 20% 帳戶的做多/做空人數比值，代表「聰明錢」的傾向。
▲ > 1.3 = 大戶偏多
▼ < 0.7 = 大戶偏空
🎚️ ATR 波動率
Average True Range
過去 N 天的平均波幅，用來判斷當前波動是否擴張（即將啟動行情）。
▲ ATR 突然擴張 = 行情可能啟動
🐋聰明錢信號解說▼
信號條件意義
🐋 機構建多倉頂級多空 >1.3 + 倉位比 >1.15大戶在悄悄建多，可能是提前佈局
⚡ 軋空機會頂級多空 <0.7 + FR 正值大戶做空但散戶強多，轉多可能快速軋空
💎 多頭優勢頂級多空 >1.5 + FR 負大戶偏多且空頭在付費，多頭結構有利
🔻 極端空頭多空比與倉位比都 <0.8 + FR 負全面看空，留意是否為反向指標

🔍 領先分（Early Score）是什麼？
台股的領先分由 BB 壓縮（布林帶收窄）+ 量能階梯 + 沉睡甦醒 三項指標組成，滿分約 43 分。
這些指標代表「尚未大漲但蓄勢完成」的狀態——法人悄悄建倉、成交量溫和放大、但股價還沒有明顯動作。
領先分高 = 提前佈局機會；領先分低但總分高 = 可能已啟動，追高風險較大。
預設門檻：領先分 ≥ 20（約 47%）才進入榜單。
📈 MA20/MA60 趨勢修正：總分最終乘以趨勢乘數（×0.82 ~ ×1.12）。多頭排列（價>MA20>MA60）乘 ×1.12 加成；空頭排列（價<MA20<MA60）乘 ×0.82 打折，避免逆勢操作。
📡指標解說▼
🏦 外資
Foreign Institutional Investors (FINI)
外國法人（基金、投行）的買賣超金額。連續買超天數越多，信號越強。
▲ 連買 3 天以上 = 強多信號
▼ 轉賣 = 注意停損
🏛️ 投信
Domestic Investment Trust
國內投信基金的買賣超。投信通常在月底作帳，季底影響力更大。
▲ 投信 + 外資同買 = 法人聯手
💳 融資
Margin Trading
散戶向券商借錢買股。融資大增代表散戶追多，往往是短期高點警訊。
▲ 低融資 + 股價上漲 = 法人推動
▼ 融資暴增 = 小心散戶追高
📉 融券
Short Selling
借股賣出的空頭部位。融券增加代表空頭壓力，但也是潛在軋空來源。
▲ 高融券 + 股價強 = 軋空潛力
📉 CVD 背離
Cumulative Volume Delta
主動買量與主動賣量的累積差值。CVD 上升但價格不漲 = 隱性買盤。
▲ CVD 向上背離 = 潛在多頭
😴 沉睡甦醒
Sleeping Wake Signal
長期低量橫盤後，成交量突然放大到歷史均量 2 倍以上，代表資金開始注意此股。
▲ 觸發沉睡甦醒 = 關注訊號

💡 早分（Early Score）是什麼？
美股的早分由 BB 壓縮 + 量能放大 + ATR 擴張 三項指標組成，滿分約 45 分。
早分高代表「股價尚未大漲，但技術面已悄悄蓄勢完成」——通常是機構在建倉、市場還沒注意到的階段。
早分 ≥ 18（約 40%）才進入榜單，避免追高已啟動的股票。可用 /set_us_early 自訂門檻。
💡 RS Rating（相對強度評分）是 IBD 投資法的核心指標，0-99 分，代表過去 1 年這支股票相對所有股票的強弱百分位。RS 80 以上表示打敗了 80% 的股票，是強勢股的關鍵門檻。
🏆 52 週高點邏輯：IBD 策略買近新高不買低點。距 52 週高點 5% 內 +4 分，15% 內 +2 分；超過 40% 以下則扣分，代表趨勢尚未恢復。
📡指標解說▼
📊 RS Rating
Relative Strength Rating (IBD 風格)
計算過去 1 年股票報酬率相對所有掃描股的百分位排名。RS 80 = 打敗 80% 的股票。
▲ RS ≥ 80 = 強勢領導股
▼ RS < 50 = 表現落後
🏛️ A/D Ratio
Accumulation/Distribution Ratio
上漲日的成交量總和 / 下跌日的成交量總和。比值大於 1.2 代表法人在悄悄買入（累積）。
▲ A/D ≥ 1.5 = 強力買入 / A/D ≥ 1.2 = 法人在買
▼ A/D < 0.8 = 法人在賣
⚡ Short Float
Short Interest % of Float
流通股中被放空的比例。空頭比例高 + 股價突然強勢，容易引發軋空（Short Squeeze）。
▲ 高空頭比 + 轉強 = 軋空潛力
🏦 法人持股
Institutional Ownership %
基金、機構投資人持有的股份比例。法人持股高代表獲得機構認可，但首次啟動前往往尚未被持有。
▲ 持股 ≥ 60% = 機構認可
